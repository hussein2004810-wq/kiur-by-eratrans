# KIUR by ERATRANS

منصة عربية مفتوحة المصدر للاختبارات الطبية متعددة الخيارات، وهي مشروع تابع لقناة **ERATRANS** المهتمة بالمحتوى الطبي وترجمة المحاضرات الجامعية.

## المزايا

- تسجيل الطلاب والدخول الآمن عبر ChatGPT Sites.
- تصفح هرمي: القسم ← المرحلة ← المادة ← المحاضرة ← الاختبار.
- بحث عن الاختبارات والمحاضرات.
- حفظ تقدم الطالب والنتائج وسجل المحاولات.
- عرض الإجابات الخاطئة وشرح الإجابة بعد إكمال الاختبار.
- روابط مباشرة لمشاركة الاختبارات والمحاضرات.
- لوحة مشرف لإدارة الهيكل الأكاديمي والاختبارات والأسئلة.
- إحصاءات الطلاب ونسبهم وسجل تدقيق للتغييرات.
- واجهة عربية متجاوبة تعمل على الهاتف والحاسوب.

## التقنية

- React 18 وTypeScript وVite.
- Cloudflare Worker مُجهّز بواسطة OpenAI Sites.
- قاعدة بيانات D1/SQLite ومخططات SQL داخل مجلد `drizzle`.
- pnpm لإدارة الحزم.

## التشغيل للتطوير

المتطلبات: Node.js حديث وpnpm.

```bash
git clone YOUR_REPOSITORY_URL
cd kiur-by-eratrans
pnpm install
pnpm dev
```

ثم افتح `http://localhost:5173`. تعمل الواجهة محليًا، بينما تسجيل الدخول وقاعدة البيانات الكاملة يحتاجان إلى بيئة OpenAI Sites المنشورة.

## البناء والاختبار

```bash
pnpm build
node scripts/test-migrations.mjs
node scripts/test-catalog-api.mjs
node scripts/test-share-links.mjs
node scripts/test-student-insights.mjs
node scripts/test-worker.mjs
```

## إنشاء نسختك المنشورة

1. انسخ المستودع إلى حسابك أو نفّذ Fork.
2. افتح المشروع في Codex واستخدم Sites لإنشاء موقع جديد؛ ملف `.openai/hosting.json` لا يحتوي على معرّف موقع المالك الأصلي.
3. أنشئ قاعدة D1 بالربط `DB` وطبّق ملفات `drizzle` بالترتيب.
4. أضف متغير بيئة باسم `ADMIN_EMAIL` واجعل قيمته بريد حساب المشرف.
5. ابنِ المشروع ثم انشر الإصدار من خلال Sites.

لا تضع كلمات مرور أو رموز دخول داخل المستودع. ملف `.env` مستبعد تلقائيًا من Git، واستخدم `.env.example` كمرجع فقط.

## بنية المشروع

- `src/`: الواجهة والمكوّنات.
- `worker/`: واجهات API والمصادقة ومنطق الاختبارات والإدارة.
- `drizzle/`: مخططات قاعدة البيانات وترقياتها.
- `scripts/`: اختبارات التكامل وأدوات تجهيز البناء.
- `.openai/hosting.json`: تعريف روابط خدمات Sites دون معرّف خاص بمالك.
