# رفّي الدراسي — KIUR by ERATRANS

حالة النسخة: تعديلات محلية للمراجعة؛ لا نشر إلى الاستضافة ولا دفع إلى GitHub في هذه المهمة.

## الاتجاه والنطاق

استلهام رحلة «الرف ثم المحتوى» من [Complete Shelf](https://github.com/MengTo/complete-shelf)، بتنفيذ React أصلي فوق بيانات KIUR الحالية. لم يُنسخ كود المستودع أو صوره أو أصواته؛ لم تظهر رخصة محددة في النسخة المفحوصة `b0b532411a9ba9f56ebcebdffe06747be0dcd84d`.

راجعت إرشادات [frontend-design الرسمية من Anthropic](https://github.com/anthropics/skills/tree/main/skills/frontend-design) واستخدمت مبادئ وضوح المحتوى، الهوية المميزة، الحركة الهادئة، والرسائل الموجهة للإجراء. لم تُثبّت إضافة عالمية أو تتغير إعدادات Codex.

التصميم يحافظ على خط Segoe UI/Tahoma العربي الموجود. الألوان الأساسية: أخضر KIUR `#0a594b`، حبر `#18332d`، نعناع `#dff5ef`، ورق `#ffffff`، نص ثانوي أوضح `#526c63`، ولمسة نحاسية `#93602f`. الرف هو العنصر البارز؛ بقية أدوات التعلم هادئة، ومحاذاة المحتوى RTL. يستخدم التخطيط بطاقات عمودية على الهاتف ولا يحتاج إلى WebGL أو صوت.

## ما نُفذ

- الصفحة الرئيسية تفتح الرف الحقيقي لمواد المرحلة المسجلة، ثم محاضرات المادة، ثم الاختبارات. التصفح وحده لا ينشئ محاولة.
- لكل مادة عدد محاضراتها واختباراتها، وآخر نتيجة مرتبطة بمعرف الاختبار، مع عودة إلى آخر مادة اختُبرت.
- لا خلط بين مواد متشابهة الأسماء، ولا نسبة إكمال منهج مستنتجة من محاولات محدودة. النص يوضح أن مصدر النتائج آخر 100 محاولة مكتملة.
- البحث يدعم المادة والمحاضرة والاختبار، ويتجاهل التشكيل والتطويل وأشكال الألف وحالة الحروف؛ يبحث في البيانات التي أعادها الخادم، لا في محتوى إضافي مخفي.
- المحاضرات المطابقة تظهر حتى قبل نشر اختبارات لها. الروابط المباشرة ومشاركة المحاضرة والاختبار محفوظة.
- زر فتح الاختبار يُقفل أثناء الطلب، مع قفل متزامن إضافي لمنع النقر المكرر. المؤقت واستئناف المحاولة وتحديد الأهلية تظل على الخادم.
- حالات تحميل وخطأ وإعادة محاولة، ورسائل فراغ عملية. لا تعرض الشاشة الفارغة باعتبارها عدم وجود محتوى أثناء التحميل.
- عرض أول 24 اختبارًا وزر تحميل المزيد من البيانات الموجودة في الذاكرة؛ لم يتغير حجم استجابة API.
- زر تبديل إلى العرض التقليدي يحافظ على المسار السابق. يُحفظ تفضيل العرض فقط في التخزين المحلي، دون أسئلة أو إجابات أو بيانات حسابات.
- بيانات المسار المسجل قابلة للعرض؛ لا محاولة لتجاوز قفل تعديل مسار الطالب على الخادم.
- حد أدنى 44px لأزرار الرف، أسماء وصول للبحث، مسار تنقل، نقل التركيز إلى عنوان المحتوى عند الاختيار، وتقليل الحركة.

تغيير الخادم الوحيد هو إضافة `testId` إلى `/api/me/history` للاستدلال الدقيق على المادة. بقي شرط `a.user_id = user.id`، وحالة المحاولة المكتملة، وحد 100، و`cache-control: no-store` كما هي. لا ترحيل لقاعدة البيانات، ولا مكتبات جديدة، ولا تغيير للأسرار أو الأدوار.

## النظام الهجين

جرت محاولتان فعليتان لاستدعاء `Hybrid.ps1 -Mode Draft -Profile quick` لمراجعة UX بنص مصطنع دون ملفات أو بيانات طلاب. أوقف الحارس المحاولة الأولى عند 0.85 GB RAM متاحة، والثانية عند 0.61 GB. لم تُعطّل حماية حد 1 GB، ولم تُغلق برامج المستخدم، ولم يُجر استدلال ناجح. لذلك لا تنسب أي توصية أو اختبار في هذا التعديل إلى Ollama. يلزم تحرير الذاكرة ثم إعادة المراجعة المحلية إذا رغب المالك.

## التحقق

- فحص TypeScript وبناء Vite وتجهيز حزمة Sites المحلية.
- مجموعات `test:node`: migrations، catalog-api، worker، student-insights، share-links، attempt-shuffle، security، auth، scoped-access، exam-features، governance-features، student-bans، study-shelf.
- اختبارات الرف الجديدة تشمل البحث العربي، ثبات البيانات وعدم تعديلها، المواد المتشابهة، المحاضرات الفارغة، تواريخ UTC، ست حالات عرض عبر React server rendering، الهروب النصي من HTML، تحديد عدد البطاقات، وعدم بدء محاولة بمجرد العرض.
- اختبار API على SQLite معزولة يثبت منع الزائر، فصل سجل طالبين حتى مع `userId` مخالف في الرابط، وإرجاع `testId` للمحاولات المكتملة فقط.
- لا تواصل مع قاعدة الإنتاج أو الحسابات الحقيقية أثناء الاختبارات. اختبار 500 قراءة محلية الموجود سابقًا ليس إثباتًا لتحمل 500 طالب على الاستضافة.

## ما لم يُنفذ / قبل النشر

- لم تُنفذ مراجعة تفاعلية داخل متصفح الهاتف أو باستخدام قارئ شاشة؛ يلزم تنفيذها على النسخة التجريبية قبل اعتبار التجربة معتمدة بصريًا ووظيفيًا بالكامل.
- عرض الكتب ثلاثي الأبعاد والأطلس السريري المستقل مؤجلان. لا حاجة لإضافة حمل رسومي أو إظهار صور/إجابات محمية لمجرد استلهام شكل الرف.
- تحذير Vite الحالي لحزمة ExcelJS الكبيرة باقٍ؛ الأداة محملة بشكل منفصل، ولم يُخف التحذير أو تُغيّر الحدود لإسكات البناء.
- النشر ورفع التعديلات إلى GitHub يتطلبان موافقة المالك؛ لا توجد مهام تلقائية جديدة.
