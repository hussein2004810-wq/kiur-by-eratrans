يتم تسليم جميع إجاباتك المسجلة تلقائياً وبشكل نهائي بمجرد وصول المؤقت إلى 00:00:00، دون الحاجة لتدخلك.

visibility_off حجب المفاتيح والتفسيرات أثناء الاختبار

تُحجب الإجابات الصحيحة والتعليلات السريرية طوال فترة الاختبار، وتظهر التحليلات المقارنة والتفسيرات المفصلة فور الاعتماد النهائي.
