1. عدد الأسئلة المستهدفة للجلسة

Standard Block Sizing
info

سيتم استخراج 40 سؤالاً متوازناً عشوائياً وفق المعايير السريرية لمحاكاة بلوك امتحاني حقيقي متوافق مع لوائح واختبارات الهيئة السعودية للتخصصات الصحية (SMLE) وامتحان الكفاءة الدولي (IFOM).

2. نمط التدريب والتقييم السريري

Pedagogical Mode
وضع التدريب السريري
Tutor Mode

تظهر الإجابة الصحيحة والتفسير الطبي الفسيولوجي المباشر عقب الإجابة على كل سيناريو سريري فوراً. مثالي للاستذكار العميق وتثبيت المفاهيم.

timer_off لا يتطلب ضغط الوقت
النمط النشط للمحاكاة
وضع الاختبار المحاكي
Exam Mode

أجب عن كامل أسئلة البلوك دون معرفة صحة الإجابات أثناء الحل. تُعرض التفسيرات الشاملة، مصفوفة تحليل الأداء، ومعدل زمن الحل فور تسليم الاختبار كاملاً.

verified_user محاكاة بيئة الامتحان الرسمي (Anti-bias Cognitive Protocol)

3. توقيت الاختبار والتحكم بالزمن

schedule محسوب بدقة: 90 ثانية / سؤال
المدة: دقيقة
psychology

توصية الأكاديمية السريرية: التدرب بمعدل 75–90 ثانية لكل سيناريو سريري يرفع كفاءة إدارة وقت الامتحان الفعلي بنسبة 35% ويقلل التشتت الذهني.

4. سلوك إظهار النتائج والتفسيرات

lock مقيد لضمان معيارية المحاكاة
lock_clock حجب التفسيرات مفعل تلقائياً في وضع الامتحان

لمنع الانحياز الإدراكي (Cognitive Confirmation Bias)، يتم تعطيل إشارات الصواب والخطأ أثناء الجلسة. ستظهر التفاصيل الكاملة متضمنة مراجع UpToDate وPubMed فور التسليم النهائي.

tune إعدادات متقدمة وخوارزميات الفرز (ترتيب عشوائي • خلط الخيارات • استبعاد المحفوظ)
