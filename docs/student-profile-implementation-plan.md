# خطة تنفيذ بروفايل الطالب في KIUR

## بوابة الإنجاز

لا تُنشر نسخة جزئية. يكتمل العمل فقط بعد نجاح اختبارات العزل بين الطلاب، واختبارات الجلسات، والاختبارات الوظيفية الكاملة، وبناء الإنتاج.

## الدفعة الأولى: الأساس والهوية

- صفحة بروفايل مستقلة متجاوبة ومتصلة بتنقل الطالب.
- الاسم والصورة الاختيارية الآمنة/الأحرف الأولى، البريد الموثق، ورمز الطالب.
- المسار الأكاديمي الكامل وزر طلب تصحيحه، مع رقم الطلب والحالة والتاريخ.
- مركز دعم داخل المنصة مرتبط بالطالب، مع سجل الردود والحالات.

## الدفعة الثانية: التعلم والإنجاز

- المتوسط، أعلى وآخر نتيجة، عدد المحاولات، النجاح والرسوب.
- تطور أسبوعي وأداء حسب المادة دون ترتيب علني.
- المواد الضعيفة، خطة المراجعة، الاختبارات المحفوظة والمفضلة وآخر النشاطات.
- الشهادات القابلة للتنزيل والمشاركة والتحقق.
- شارات علمية اختيارية خاصة بالطالب ويمكنه إخفاؤها.

## الدفعة الثالثة: الخصوصية والأمان

- إعدادات ظهور الصورة والشارات والنشاط.
- عرض الجلسات النشطة بأوصاف غير حساسة وإتاحة إنهاء جلسة أو جميع الجلسات الأخرى.
- تغيير كلمة المرور عبر المسار الآمن الحالي.
- منع وصول طالب إلى بيانات طالب آخر، وحصر وصول الكادر بنطاق الصلاحية.
- سجل نشاط حساب مختصر لا يعرض معرف الجهاز الخام أو البيانات السرية.

## الدفعة الرابعة: التحقق والتسليم

- اختبارات API وواجهة وعزل صلاحيات وأجهزة هاتف ولابتوب.
- تشغيل مجموعة اختبارات المشروع كاملة وبناء الإنتاج.
- مراجعة التغييرات والأسرار والملفات المتولدة.
- رفع الالتزامات إلى GitHub ثم نشر إصدار Sites كامل واحد.

## قرارات تجربة المستخدم

- البروفايل خاص افتراضيًا ولا توجد لوحة ترتيب علنية.
- الصورة اختيارية، والأحرف الأولى بديل دائم.
- المؤشرات تشرح مصدرها وفترتها ولا تقدم تشخيصًا طبيًا.
- طلب تصحيح المسار والدعم قابلان للتتبع من صفحة واحدة.
- كل إجراء أمني أو حذف جلسة يحتاج تأكيدًا ورسالة نتيجة واضحة.
