# برومبت Antigravity لمتابعة تطوير KIUR

أنت تعمل داخل مستودع KIUR الحالي. ابدأ من آخر نسخة موجودة ولا تعِد إنشاء المشروع ولا تستبدل الواجهة العامة. اقرأ `AGENTS.md`، لكن لا تستخدم Ollama أو فريق Ollama نهائيًا بناءً على قرار المالك الأحدث. لا تستخدم نماذج أو خدمات مدفوعة.

## الهدف

أكمل رفع جودة واجهات المشرفين والكوادر المبنية على Google Stitch مع الحفاظ على كل الوظائف الحقيقية، وامنع عودة الواجهة الإدارية القديمة أو أي بيانات وهمية.

## حقائق معمارية ملزمة

1. الواجهة الإدارية الوحيدة هي `src/stitch/components/StitchAdminWorkspace.tsx` مع `src/stitch/stitch-admin.css`.
2. لا تعِد إنشاء أو استرجاع `StitchAdminSuite.tsx` أو `src/admin-shell.css` أو الغلاف المزدوج القديم في `StitchApp.tsx`.
3. `RealAppV2.tsx` يمرر المديرين الحقيقيين إلى `StitchAdminWorkspace`: الاختبارات، الاستيراد، الهيكل، الطلاب والتصدير، تغييرات المسار، النقاط، اللمحات، المكتبة، الحسابات، الحظر والسجلات.
4. Firebase Authentication هو خدمة Firebase المنفذة للمصادقة. لا تنقل قاعدة البيانات إلى Firestore ولا تضف خدمة Firebase غير منفذة من دون قرار صريح. تبقى D1 مصدر البيانات authoritative وR2 للملفات.
5. لا تعرض أي رقم أو نشاط أو مستخدم وهمي. استخدم API حقيقيًا، وحالة تحميل، وحالة فارغة صادقة، وحالة خطأ قابلة لإعادة المحاولة.
6. الصلاحيات يجب أن تُفرض في الخادم أولًا. إخفاء الزر في الواجهة ليس تفويضًا أمنيًا.

## العمل المطلوب بالترتيب

### 1. تدقيق وظيفي تفصيلي

- أنشئ مصفوفة لكل دور: owner، admin، teacher ولكل صلاحية ونطاق جامعة/كلية/قسم/مرحلة/مادة.
- اختبر كل زر ونموذج وحالة تحميل وخطأ وحالة فارغة في الأقسام الاثني عشر.
- أضف اختبارات تكامل لأي تدفق غير مغطى، خصوصًا فشل الشبكة، النقر المكرر، تعارض التحديث، والطلبات خارج النطاق.
- لا تغيّر منطقًا ناجحًا لمجرد إعادة تنسيق الشيفرة.

### 2. تحسين بنية الواجهة

- قسّم كتلة الإدارة في `RealAppV2.tsx` إلى مكونات صغيرة مكتوبة TypeScript من دون تغيير عقود API.
- أضف Error Boundary لكل وحدة lazy مع زر إعادة المحاولة ورسالة عربية واضحة ورقم متابعة إن توفر.
- اجعل القسم الحالي قابلًا للحفظ في URL أو session state من دون كشف قسم غير مسموح بعد تغير الصلاحيات.
- أضف حالات loading/skeleton خفيفة من دون blur ثقيل أو مؤثرات تسبب تأخر الرسم على الهاتف.

### 3. قابلية استخدام 600 طالب

- حافظ على البحث المتأخر والإلغاء عبر AbortController.
- استخدم pagination أو virtualization لجداول الطلاب والسجلات عند الحاجة، ولا تحمل آلاف الصفوف دفعة واحدة.
- ثبّت الفلاتر المهمة، واحتفظ بها أثناء فتح تفاصيل طالب والعودة.
- صدّر النتائج في الخادم أو على دفعات إذا تجاوزت البيانات حدًا آمنًا للذاكرة.

### 4. جودة Google Stitch

- استخدم حصريًا رموز `--stitch-*` والأسطح والمسافات ونصف الأقطار الموجودة.
- افحص light/dark عند 390×844 و768×1024 و1366×768 و1920×1080.
- لا تستخدم ألوانًا صلبة جديدة ولا الأخضر كلون علامة تجارية؛ النجاح/الخطأ دلاليان فقط وبدرجة يمكن قراءتها.
- حافظ على RTL، أهداف لمس 44px، focus مرئي، keyboard navigation، `aria-current` و`aria-expanded`، و`prefers-reduced-motion`.
- لا تستخدم emoji أو SVG يدوي أو CSS art؛ استخدم Lucide أو أصول المشروع.

### 5. الأمن وعدم العبث

- لا تطبع كلمات المرور أو الرموز أو البريد الكامل في السجلات التقنية.
- لا تضع `.env` أو مفاتيح Firebase أو أسرار الإنتاج في الشيفرة أو Git.
- اختبر IDOR، نطاق الصلاحيات، CSRF/origin، rate limits، رفع الملفات، والتصدير.
- لا تحذف بيانات إنتاج ولا تشغّل migration مدمرة. أي migration جديدة يجب أن تكون forward-only وقابلة للاختبار على قاعدة محلية.

## أوامر التحقق الإلزامية

```powershell
pnpm install --frozen-lockfile --ignore-scripts
pnpm typecheck
pnpm build
$env:CI='true'; pnpm test:node
```

بعدها نفّذ QA بصريًا وتفاعليًا في متصفح المستخدم، وسجّل النتيجة في `design-qa.md`. لا تعتبر screenshots وحدها اختبارًا: اختبر النقر، الإدخال، الفلاتر، القوائم، الحوارات، الأخطاء، والعودة.

## شروط التوقف

- توقف ولا تنشر إذا فشل build أو typecheck أو أي اختبار أمن/صلاحيات.
- توقف إذا احتجت سرًا أو إعداد Firebase Console غير متاح، واكتب المطلوب بدقة بدل اختلاق قيمة.
- لا تدفع إلى GitHub ولا تنشر إلى الإنتاج إلا بموافقة المالك الصريحة بعد عرض ملخص التغييرات والاختبارات.

## المخرجات المطلوبة

1. قائمة الملفات المعدلة ولماذا.
2. مصفوفة الوظائف والصلاحيات التي تم اختبارها.
3. نتائج الأوامر الأربعة بالأرقام.
4. صور QA للوضعين وعلى الهاتف واللابتوب.
5. قائمة قصيرة بما بقي خارجيًا أو يحتاج قرار المالك.
